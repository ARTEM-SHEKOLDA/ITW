# ITW - Projekt č. 2 - vlastní profilové webové prezentace

### 1. Základní informace
* **Autor:** Artem Antonenko
* **Login:** xantona00
* **URL projektu:** [[https://artem-shekolda.github.io/ITW/](https://artem-shekolda.github.io/ITW/)](https://artem-shekolda.github.io/ITW/)

### 2. Použité technologie
* **HTML5 & CSS3:** Základní sémantická struktura a vizuální styl webu.
* **Responsivita:** Web je plně optimalizován pro různá rozlišení (mobily, tablety) pomocí souboru mobile.css.
* **Typografie:** Využití rodiny písem Istok Web a Iosevka Charon z knihovny Google Fonts.
* **Verzování a hosting:** Projekt je spravován v systému Git a publikován prostřednictvím GitHub Pages.

### 3. Zdroje a grafika
* **Ikony v patičce:** Byly vybrány a staženy pomocí pluginu Iconify v aplikaci Figma.
* **Ostatní obrazky:** Veškeré ostatní obrázky, ilustrace a náhledy v galerii jsou mým autorským dílem.

### 4. Testování
* Hlavní testování funkčnosti a vzhledu proběhlo v prohlížeči Mozilla Firefox.

### 5. Prohlášení o využití AI a externích nástrojů

* **DeepL.com:** Tento nástroj byl využit k asistenci při překladu a lokalizaci některých textových prvků webu do češtiny pro zajištění správné terminologie.
* **Využití AI (Gemini):** 
    * AI byla využita jako studijní podpora pro pochopení principů JavaScriptu a specifických vlastností CSS (např. implementace lineárních a radiálních gradientů).
    * S AI byly konzultovány technické postupy pro realizaci prvků, které nebyly v době tvorby součástí mých hlubších znalostí.
* **Způsob zapracování:** Veškerý kód (HTML, CSS, JS) byl napsán ručně. Návrhy a funkce poskytnuté AI byly před jejich implementací podrobně studovány, abych plně porozuměl jejich logice a funkčnosti v kontextu mého projektu.
